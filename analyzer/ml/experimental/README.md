# Experimental ML Features

This directory contains experimental, research-oriented, or work-in-progress ML features for QueryGrade.

## ⚠️ Important Notice

**These modules are NOT production-ready** and should be used with caution:

- APIs may change without notice
- Implementations may be incomplete
- Testing coverage may be minimal
- Performance is not guaranteed
- Features may be removed in future releases

## Purpose

This directory serves as a sandbox for:

1. **Research & Development**: Testing new ML algorithms and approaches
2. **Prototyping**: Rapid prototyping of new features
3. **Experimental Features**: Features that need more validation before production
4. **Legacy Code**: Deprecated modules being phased out

## Guidelines

### For Contributors

When adding experimental code:

1. Clearly document what the module does and why it's experimental
2. Include a `STATUS.md` file explaining:
   - Current state of development
   - Known issues or limitations
   - Path to production (if applicable)
   - Expected timeline or removal date

### For Users

When using experimental features:

1. Do **NOT** use in production environments
2. Expect breaking changes
3. Report issues but understand they may not be prioritized
4. Consider experimental code as "reference implementations"

## Moving to Production

For a module to graduate from experimental to production:

1. ✅ Complete implementation with all features working
2. ✅ Comprehensive test coverage (>80%)
3. ✅ Documentation including usage examples
4. ✅ Performance benchmarks showing acceptable performance
5. ✅ Code review and approval from core team
6. ✅ Migration plan for moving to appropriate production package
